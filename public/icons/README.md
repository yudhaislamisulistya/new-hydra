# Ikon HYDRA

Ikon dibuat menggunakan imagegen bawaan, bukan logo Next.js. Versi 192/512 px,
Apple Touch Icon, dan favicon diturunkan dari gambar yang sama.

Prompt final: Production square application icon and favicon for NEW HYDRA,
an Indonesian elementary-school hydration tracker. A polished, playful,
simple friendly aqua water-droplet mascot on a vivid deep-blue rounded-square
app tile; cheerful eyes and soft smile, white highlight, blue/cyan/teal palette,
strong contrast and readable silhouette at 32 pixels, centered safe area,
restrained soft dimensional lighting. No text, no watermark, no extra objects,
no Next.js logo.
